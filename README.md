## ◆ About

Economist from **Universidad Militar Nueva Granada** and Master's student in **Data Science at Pontificia Universidad Católica de Chile**.

I've built data areas from scratch in startups: aligning stakeholders on the metrics that matter, designing reporting from executive dashboards to fully automated daily reports, and turning CRM and web data (HubSpot, Pipedrive, Google Analytics) into decisions.

My work sits where **economics, causal inference and data engineering** meet. Every project here runs on real data, is reproducible end to end, and is built to answer a question someone actually has to decide on.
